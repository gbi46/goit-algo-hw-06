# Порівняння алгоритмів пошуку підрядка

Алгоритми: **Бойєра–Мура (Горспула)**, **Кнута–Морріса–Пратта (KMP)**, **Рабіна–Карпа**.
Вимірювання зроблено `timeit` на двох текстах ("стаття 1", "стаття 2"). Для кожного тексту взято два підрядки:
- *існуючий* (фрагмент з самого тексту),
- *вигаданий* (відсутній у тексті).
Кожен запуск усереднено по кількох повтореннях.

## Висновки
1. **Бойєр–Мур (Горспул)** стабільно найшвидший у наших даних як для наявних, так і для відсутніх підрядків. Це очікувано для довільного тексту: порівняння з кінця та великі стрибки дають перевагу.
2. **KMP** прогнозовано поступається BM на випадковому тексті, але демонструє більш передбачувану швидкість незалежно від вмісту підрядка.
3. **Рабін–Карп** вийшов найповільнішим у цій реалізації через додаткові витрати на хешування та перевірки збігів; він виграє зазвичай у сценаріях пошуку **багатьох** підрядків водночас або при потоковій обробці.

> Зауваження: файли мають помірний обсяг, тому абсолютні часи — у десятках/сотнях мікросекунд; для великих корпусів відносні тренди збережуться, але розриви зростуть.
